# voyago-

Voyago is a responsive multi-page travel agency website built with HTML, CSS and vanilla JavaScript.

## Pages
- `index.html` – Home
- `destinations.html` – Destinations
- `packages.html` – Travel packages
- `about.html` – About us
- `testimonials.html` – Reviews
- `contact.html` – Contact & booking

Content (destinations, packages, reviews) lives in `js/data.js`.
